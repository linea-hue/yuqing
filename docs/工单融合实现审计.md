# 工单 1 + 5/6/8/10 深度融合实现审计

## 业务主链

```text
买家/客服文本或语音
  → Critic + DLP 安全网关
  → 规则优先 / 模型补充 / Fallback 意图路由
  → 订单、支付、物流、售后上下文
  → Evidence/OCR + Fraud + Sentiment 并行
  → 带 ACL、版本、有效期、阈值和引用的 RAG
  → 确定性金额与风险策略
  → 自动退款或 SUSPENDED_HUMAN
  → 主管审批恢复 / 幂等退款
  → Trace、Checkpoint、Stream、评测与运营指标
```

## 能力矩阵

| 工单 | 深层能力 | 当前实现 | 生产替换点 |
|---|---|---|---|
| 1 | 客诉接入、证据、欺诈、舆情、金额决策、人工审批 | `app/decision.py` 统一状态机，状态为 `RUNNING / SUSPENDED_HUMAN / COMPLETED`；自动退款与人工恢复均写入 Trace | PostgreSQL、真实 OCR、支付退款网关、Redis Checkpointer/Streams |
| 5 | Trace、Golden Dataset、成本与时延、沙箱、死信 | `app/evaluation.py` 动态评测 100 条业务样本 + 108 条攻击样本；`app/sandbox.py` 仅在临时目录解析 Office/CSV/JSON；意图异常写 DLQ | Langfuse/LangSmith、CubeSandbox/容器、异步 Worker |
| 6 | Critic、DLP、Tool Policy、最小权限 | `app/security.py` 注入/越狱/角色冒充检测，手机号/身份证/邮箱/银行卡/API Key 脱敏；退款工具必须有审批、角色和金额策略 | 企业 IAM/OIDC、外部 DLP、策略引擎、密钥托管 |
| 8 | 多级意图、JSON 校验、超时/熔断/Fallback、周期评测 | `app/intent.py` 规则 → 严格 JSON 模型 → Fallback，解析错误进入 DLQ，熔断器连续失败打开；评测数据集 100 条 | LangGraph 节点、Redis 共享熔断、真实 LLM Judge、CronJob |
| 10 | 语音输入、RAG、安全、打断 | `/api/voice/turn` 与 `/ws/voice` 共用安全/意图/RAG；浏览器 ASR + 可打断 TTS，`/interrupt` 清空队列 | WebRTC 媒体层、VAD、流式 STT/LLM/TTS、35 路压测 |

## 重复功能处理

已删除未被路由、测试或文档引用的旧页面：`buyer.html`、`buyer_store.html`、`buyer_enterprise.html`、`cs.html`、`ops.html`。正式入口仅保留：

- `/buyer` 买家服务系统
